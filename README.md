# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Notes are categorized as Personal, Work, or Study and are automatically saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes with categories
- Delete notes
- Search notes
- Input validation
- Automatic note counting
- Data persistence with localStorage
- Responsive design

## How to Run Locally

1. Clone or download the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Add, search, and manage notes.
